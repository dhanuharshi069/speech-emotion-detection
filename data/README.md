# Dataset

This project uses the RAVDESS emotional speech audio set (speech only).

1. Download `Audio_Speech_Actors_01-24.zip` from the official Zenodo record:
   https://zenodo.org/records/1188976
2. Extract it so the layout is:

   data/raw/Actor_01/03-01-01-01-01-01-01.wav
   data/raw/Actor_02/...
   ...
   data/raw/Actor_24/...

The dataset is licensed CC BY-NC-SA 4.0 and is not committed to this repository.
Citation: Livingstone & Russo (2018), "The Ryerson Audio-Visual Database of
Emotional Speech and Song (RAVDESS)", PLOS ONE.
